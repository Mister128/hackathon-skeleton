# Hackathon Skeleton

## Что это
веб-приложение для одновременной работы нескольких пользователей над одним документом.

## Что нужно
- Для Backend:
    - Node: v22.20.0
    - npm: 11.6.4 (обычно в комплекте с node)

## Запуск backend
Сначала проверьте версии `npm` и `node`
```powershell
node --version # v22.20.0 или более
npm --version # 11.6.4 или более
```

Если всё установлено, можно продолжать

```powershell
cd ./backend/ # Если ещё не перешёл
npm install
npm run start
```
После запуска сервер будет доступен по адресу `http://127.0.0.1:3001`

### Проверка работоспособности сервера:
```powershell
curl http://127.0.0.1:3001/health # в отдельном терминале
```
ИЛИ

Нажать на кнопку `fetch` на странице http://127.0.0.1:3001

## Порт
Порт зашит в server.js, строка с const port.
.env пока НЕ подключается — это TODO команды.

## Частые проблемы
EADDRINUSE - занятый порт. Поменяёте на другой.
кнопка/страница пустая - проверьте:
    - сервер написал: "server on ..."
    - curl /health вернул текст
    - в адресной строке именно 127.0.0.1 или localhost, без опечаток
