## UI
- запуск: 
```powershell
cd frontend 
npm ci
npm run dev
```
- адрес: `http://localhost:5173`
- запросы к бэкенду идут через Vite
- `http://<IP>:8080/status` работает независимо от фронта - это проверка
  бэкенда, не трогайте её и не переносите в React

Адрес: http://localhost:5173

## О package.json
Там вы сами выбираете какой "type": "commonjs"/"module" и "main": "idk.js"
build пока что просто заглушка, она удалится сама, когда вы поставите Vite или что решите в итоге

Если смените выходную папку (`build.outDir`) - сообщите @Misterr_Y
  и обновите path в actions/upload-artifact. Иначе CI упадёт красным
  «No files were found» - это не баг CI, это он защищает деплой от пустой сборки.

`dist/` в git не коммитится (см. .gitignore). 
Локальная сборка - только для проверки, что job пройдёт.

## Как фронт ходит на бэкенд
Запросы идут через dev-proxy Vite: браузер обращается к :5173, Vite
пересылает на :8080.

## Проверить, что proxy работает
DevTools -> Network: запрос должен уходить на
:5173/..., а не на :8080/....

## Переменные
Файл: frontend/.env. Только с префиксом VITE_ попадают в код.
Пример: `VITE_API_URL=http://localhost:8080`

Внимание: всё, что в VITE_, видно браузеру. Секретов там не бывает.
