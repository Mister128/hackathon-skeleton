# Backend

Node-сервер. Запуск:
```powershell
cd backend
npm ci
npm start
```

Адрес: http://127.0.0.1:8080 (порт из backend/.env, fallback 8080)
Проверка, что жив (отдельный терминал):

```cmd
curl http://127.0.0.1:8080/health
```

## Порт
Читается из backend/.env -> PORT. Если файла нет, сервер молча берёт 8080.
Путь в скрипте запуска: node --env-file-if-exists=./.env server.js

Живой ответ вида {"ok":true,"time":"..."} = сервер здоров.
Страница статуса для людей: http://127.0.0.1:8080/status

## CI 
Контракт /health - не ломать
CI проверяет:

- HTTP 200 на GET /health
- Content-Type: application/json
- тело содержит "ok":true

Это единственная точка, на которую завязан пайплайн. При переносе
на Yjs-сервер сохрани эндпоинт с той же формой - иначе CI красный,
и разбираться будет тот, кто мержил.

/status отдаётся тем же процессом с тем же origin. Находиться может только в
backend/pages/ - в React его переносить не нужно: он должен работать,
даже когда фронт собран криво или лежит.
